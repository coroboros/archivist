# Changelog

Version headers distinguish scheduled syncs from manual changes with a leading emoji. Other shared changelog conventions apply:

- `🤖` for CI-authored entries (the `sync-docs` workflow)
- `🧑‍💻` for manual or human-initiated entries

Example:

```markdown
## 🧑‍💻 v1.1.0 - 18/04/2026

### Documentation
- Reformatted `LICENSE.md`

### Features
- Added search filters
```
